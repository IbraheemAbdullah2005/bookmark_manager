# 🔖 Standalone Bookmark Manager

A professional, dark-themed web application designed to help you organize and access your links cross-platform with speed and security.

**Live Demo:** [https://bookmarkmanager.42web.io](https://bookmarkmanager.42web.io)

---

## 🚀 Features

- **Secure Authentication:** User login and registration system with password hashing.
- **Environment Safety:** Sensitive credentials managed via `.env` files.
- **Database Integration:** Full-stack management using PHP and MySQL (mysqli).
- **Secure Connection:** Forced HTTPS/SSL for data protection.

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** PHP 8.x
- **Database:** MySQL
- **Deployment:** InfinityFree Hosting
- **Security:** SSL (Let's Encrypt), `.htaccess` protection, Prepared Statements
